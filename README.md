# Computational Physics & Simulation Projects

This repository contains my work in **computational physics and numerical simulations**, focusing on solving real physical problems using Python and scientific computing techniques.

---

## 📌 Projects

### Blackbody Radiation Simulation

- Simulated **blackbody radiation spectra** using:
  - Planck’s Law  
  - Rayleigh–Jeans Law  
- Verified **Wien’s Displacement Law** numerically  
- Computed **Stefan–Boltzmann constant** using numerical integration  
- Visualized intensity vs wavelength behavior  

---

### Wave Propagation Simulation (Numerical Modelling)

- Simulated **Gaussian wave packet propagation in aluminium (500 kHz)**  
- Implemented:
  - Finite Difference Method (FDM)  
  - Spectral Method (FFT-based)  
- Compared:
  - Accuracy (Mean Squared Error)  
  - Stability (Courant condition)  
  - Computational performance  
- Generated:
  - Displacement vs Position plots  
  - Amplitude vs Time signals  
  - Method comparison  

---

### Nickel Oxide Nanoparticles (Experimental Project)

- Synthesized **NiO nanoparticles using green methods**  
- Plant extracts used:
  - *Tecoma stans* (flower)  
  - *Cinnamomum tamala* (leaf)  
- Characterization:
  - UV-Vis Spectroscopy  
  - XRD  
  - SEM  
- Calculated crystallite sizes using **Scherrer equation**
